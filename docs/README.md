# Project Documentation

Choose the guide for your task:

- **Build and upload:** Create a theme ZIP without GitHub Actions and upload it
  to the live WordPress site.
- **Development:** Set up the tools and run local checks.
- **Theme source layout:** Find where Neve, GEST, WordPress, and plugin styles
  belong.
- **GitHub release:** Create a versioned release with the release workflow.
- **Dependency updates:** Update PNPM packages and GitHub Actions.

The guides describe the current project. They do not define a staging site or
an automatic rollback process.
