# Documentation Instructions

- Write in American English. Use Merriam-Webster spelling and standard American
  punctuation.
- Use clear language for readers around CEFR B1 or B2. Prefer short sentences,
  common words, and active voice. Explain technical terms when needed.
- Describe behavior that exists in the code or workflow. Mark missing features
  and future ideas as such; do not present them as available.
- Write command examples for macOS or Linux shells. Tell Windows users to use
  WSL. State when a command must run from the repository root.
- Test copy-and-paste commands when practical. Keep each command block focused
  on one task.
